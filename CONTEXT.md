# REVERB — Shared Context

## Terminology
- **Property:** a building with a Matterport model ID (`sid`) and optionally a CoStar record.
- **Room:** a Matterport room with label and dimensions (`areaFloor`, `width`, `depth`, `height`, metric).
- **Provenance:** one of `verified | estimated | assumed | missing`, attached to every input and output.
- **RT60:** time for sound to decay 60 dB. Sabine: `T = 0.161 * V / A`, per octave band.
- **Schroeder frequency:** `fs = 2000 * sqrt(RT60 / V)`. Below it, individual room modes dominate.
- **Axial modes:** `f = n * c / (2 * L)` for each dimension, `c = 343 m/s`.
- **IR:** room impulse response, a mono WAV, 48 kHz.
- **Modeled:** synthetic from geometry and assumptions. Never "measured".

## Decisions
- No MCP. A web tool only.
- The engine is deterministic Python; LLMs never produce acoustic numbers.
- Deep Agents is used only for the Noise Scout research; it must cite sources and give no dB.
- Shortlist of properties for now, extensible by adding a Matterport model ID to `shortlist.json`.
- No 3D in the MVP. No database. Cache JSON per model ID.
- Audio is convolved in the browser (Web Audio `ConvolverNode`) with an IR generated by the backend.
- Room volume = `areaFloor * height` (works for non-rectangular rooms). Shoebox used only for IR generation.
- Two people, each working solo through their own phase series (A and B) in SLICES.md; shared JSON fixtures in contract/.

## Data facts verified so far (2026-11-14)
- Matterport Model API works: `POST https://api.matterport.com/api/models/graph`, basic auth with key and token, production host only.
- Sample model `zvKHR9DHNjJ` (5836 La Mirada Ave, LA, 19 rooms) returns per-room dimensions, but some fields are missing.
- CoStar kit unpacked at `data/costar-kit/kit/`. The join works: `MatterportModelId` in `residential-listings.csv` / `commercial-properties.csv` to `data/*.jsonl`.
- Matterport units: metric; `lat` and `long` arrive as strings.
